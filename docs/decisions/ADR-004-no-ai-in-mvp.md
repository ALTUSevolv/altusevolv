# ADR-004 — Sem IA no MVP

- Status: proposed-for-approval
- Data: 2026-08-20

## Contexto

IA adiciona custo variável, privacidade, consentimento, observabilidade e dependência externa antes
de o fluxo central estar validado.

## Decisão

Não incluir IA na Fase 1 nem como dependência do fluxo central.

## Consequências

### Vantagens

- valida o problema sem confundir valor com automação;
- menor custo;
- menos exposição de dados;
- produto continua funcional sem fornecedor de IA.

### Tradeoffs

- recursos narrativos/automáticos ficam para fase posterior.

## Revisit

Fase 4, somente com caso de uso específico, benefício medido, consentimento/data-flow revisados e
limite de custo.
