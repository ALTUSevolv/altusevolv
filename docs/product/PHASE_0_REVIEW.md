## Gate da Fase 0

A Fase 0 só é formalmente encerrada após:

1. primeiro commit no GitHub oficial;
2. `bun run lint`, `bun run typecheck` e `bun run build` passando;
3. CI verde;
4. sócios registrarem as decisões acima ou aceitarem explicitamente os itens adiados.
